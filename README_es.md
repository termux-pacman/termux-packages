### Código para conectarse al repositorio:
main:
```
[main]
Server = https://service.termux-pacman.dev/main/$arch
```
x11:
```
[x11]
Server = https://service.termux-pacman.dev/x11/$arch
```
root:
```
[root]
Server = https://service.termux-pacman.dev/root/$arch
```

### Otra información:
 - Soporte para Android: 7+
 - Soporte de arquitectura: todas (aarch64, arm, x86_64, i686)
 - Firma: clave GPG de la organización termux-pacman
 - Funciona con aws
 - Repositorio principal: https://github.com/termux/termux-packages
 - Organización que mantiene el repositorio principal: [termux](https://github.com/termux)
